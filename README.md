# Little Steps Preschool website

A lightweight, responsive static website made with plain HTML, CSS and JavaScript. It has Home, About, Academics, Admissions, Events/Notices, Gallery and Contact sections, with mobile navigation and an admissions/fee/holiday notice area.

## Preview on your computer

Open `index.html` in a web browser. An internet connection is needed for the sample photos and Google Fonts. The site itself does not need a build step or software installation.

## Make it yours before publishing

1. Replace “Little Steps Preschool” with the school's real name and update the introduction and learning approach in `index.html`.
2. Replace the sample email, address, hours, admissions wording and notice copy with verified school information. Do not publish the `.example` email address.
3. Replace the sample photos with school-approved photographs. Add permission from parents/guardians before publishing photos of identifiable children. Update each image's `alt` description too.
4. Update the page title and description near the top of `index.html`.
5. Add real social media links or remove those buttons if the school does not use them.

## Publish it

For a beginner-friendly launch, create a GitHub repository, add these three website files, then enable GitHub Pages in the repository's Settings → Pages. Choose deployment from the main branch and root folder. The published address will appear in that Pages panel. Netlify and Cloudflare Pages also support static sites; upload this folder or connect the repository and use the project root, with no build command required.

## Later: parent communication assistant

The notices section is a safe starting point for manually posted fee reminders and holiday announcements. A future parent assistant could draft messages from school-approved dates and payment instructions, then require staff review before sending through the school's chosen parent channel. Keep student and family data private and avoid putting payment details in a public page.
